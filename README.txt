Anki 解密题库批量导出插件 V4.6
==================================

适用：Anki 26.09.4

目标
保留 Anki 背面「答案解析」区域的完整长文本，不再只读取 #choice_div 后面的部分兄弟节点。

V4.6 修改
- 直接读取整个「答案解析」article 的 innerText。
- 保留 article 内所有后代节点的文字，包括长段落、多个段落、列表和嵌套容器。
- 仅移除开头的「答案解析」标题和后续「答题统计」部分。
- 不设置自定义字符长度上限，不主动摘要或缩短。
- 保留 answerArticleText 原始整段文本作为导出备用字段。
- 保留 V4.5 的自动正反面切换、启动等待、Card ID 校验和重试机制。

重要说明
- XLSX 单元格本身有 Excel 的 32,767 字符限制。若单条解析超过该限制，CSV 仍可保存完整文本；请以 CSV 为完整文本备份。
- 如果 Anki 页面本身使用折叠或懒加载隐藏了部分内容，innerText 只能读取当前渲染到 DOM 的内容。

安装
1. 完全退出 Anki。
2. 工具 -> 插件 -> 打开插件文件夹。
3. 备份并删除旧的 anki_decrypted_exporter 文件夹。
4. 解压 ZIP，将其中的 anki_decrypted_exporter 文件夹复制到插件目录。
5. 重启 Anki。

使用
1. 在浏览器中选中待导出的卡片。
2. 编辑菜单 -> 批量导出解密题库 V4.6（CSV + Excel）。
3. 选择输出目录并等待完成。

输出
- 江苏省实验动物专业技能培训记录卡_解密题库_v4.6.csv
- 江苏省实验动物专业技能培训记录卡_解密题库_v4.6.xlsx
- 江苏省实验动物专业技能培训记录卡_解密题库_v4.6_异常记录.csv

注意
- 不修改原始笔记字段，不触发复习评分。
- 已通过 Python 语法编译检查，尚未在用户本机 Anki 环境实测。
- 建议先用少量卡片检查 Excel 和 CSV 的解析长度是否与 Anki 背面一致。
