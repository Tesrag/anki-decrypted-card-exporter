# Anki Decrypted Card Exporter

An Anki add-on for batch exporting decrypted content from encrypted Anki note types.

## Features

- Batch export decrypted card content.
- Extract questions and answer options.
- Identify correct answers.
- Export answer explanations.
- Preserve long explanations.
- Export data to Excel.

## How It Works

The add-on uses Anki's native card preview rendering to access decrypted card content. It does not directly modify the original encrypted note fields.

## Installation

1. Download the latest release ZIP file.
2. Extract the ZIP archive.
3. Copy the `anki_decrypted_exporter` folder into your Anki add-ons directory.
4. Restart Anki.

## Compatibility

- Anki Desktop
- Tested development version: Anki 26.09.4
- Windows

Compatibility with other Anki versions and operating systems has not yet been verified.

## Usage

1. Open Anki.
2. Launch the add-on.
3. Select the target note type.
4. Start batch export.
5. Save the exported file.
